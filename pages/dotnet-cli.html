Instrukcja obsługi .NET CLI

.NET CLI (Command Line Interface) to wieloplatformowe narzędzie służące do tworzenia, budowania, uruchamiania i publikowania aplikacji .NET. Poniższy przewodnik przedstawia najważniejsze polecenia oraz sekwencję niezbędną do uruchomienia pierwszego programu.

Kompletna sekwencja: Utworzenie i uruchomienie aplikacji konsolowej

Poniższy blok przedstawia kroki, jakie należy wykonać w terminalu, aby utworzyć i uruchomić nową aplikację:
Zestawienie podstawowych poleceń .NET CLI
Polecenie Przykład użycia Opis
dotnet --version dotnet --version Wyświetla wersję zainstalowanego zestawu SDK .NET.
dotnet --list-sdks dotnet --list-sdks Wyświetla listę wszystkich zainstalowanych na komputerze wersji SDK .NET.
dotnet new list dotnet new list Wyświetla listę dostępnych szablonów projektów, które można utworzyć.
dotnet new console dotnet new console -n Program Tworzy nowy projekt aplikacji konsolowej o zadanej nazwie.
dotnet restore dotnet restore Przywraca zależności oraz pakiety zdefiniowane w projekcie.
dotnet build dotnet build Kompiluje projekt oraz pliki źródłowe do postaci pliku wykonywalnego.
dotnet run dotnet run Kompiluje i uruchamia aplikację w jednym kroku.
dotnet clean dotnet clean Czyści katalog wyjściowy z plików powstałych podczas budowania.
